# 75. Sort Colors

**Difficulty:** Medium<br>
[View on LeetCode](https://leetcode.com/problems/sort-colors/)

---

Sort the array in place so values representing red (`0`), white (`1`), and
blue (`2`) appear in that order. Do not use a built-in sorting function.

**Example 1:**

```
Input: nums = [2,0,2,1,1,0]
Output: [0,0,1,1,2,2]
```

**Example 2:**

```
Input: nums = [2,0,1]
Output: [0,1,2]
```

**Constraints:**

- `1 <= nums.length <= 300`
- `nums[i]` is `0`, `1`, or `2`.

**Follow up:** Can you sort the array in one pass using constant extra space?
