# 1683. Invalid Tweets

**Difficulty:** Easy<br>
[View on LeetCode](https://leetcode.com/problems/invalid-tweets/)

---

A tweet is invalid when its `content` contains more than 15 characters. Return
the IDs of all invalid tweets.

**Example:**

| tweet_id | content |
|---:|---|
| 1 | Vote for Biden |
| 2 | Let us make America great again! |

Result:

| tweet_id |
|---:|
| 2 |
